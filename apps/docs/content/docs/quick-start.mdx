---
title: 快速开始
description: 从准备来源频道到检查同步结果，了解开始使用 CopyFast 的基本步骤。
---

第一次使用 CopyFast，建议先从一个来源频道和一个目标社群开始，确认流程符合需求，再逐步增加来源。

## 1. 整理同步需求

准备以下信息，方便确认接入方式：

| 信息       | 示例                         |
| ---------- | ---------------------------- |
| 来源平台   | Telegram 或 Discord          |
| 来源频道   | 需要关注的产品公告频道       |
| 目标社群   | 自己运营的社群或频道         |
| 关注的内容 | 新公告、社区动态等           |
| 运营节奏   | 需要持续关注的时段与监控频率 |

确认自己具备相应访问和转发权限。如果涉及历史消息、成员信息或特殊内容类型，请先咨询支持范围。

## 2. 下载桌面端

前往 CopyFast 营销首页，根据设备选择 Windows、Mac（Apple 芯片）或 Mac（Intel 芯片）下载入口。可用版本以页面实际提供为准。

## 3. 确认服务与接入方式

通过营销站的联系页面，将来源、目标和使用需求告知团队，确认服务方案、平台接入条件及开通方式。具体操作以当前客户端界面和团队提供的说明为准。

## 4. 检查第一条同步消息

完成配置后，用一条你有权发送的测试消息检查：

- 消息是否到达预期的目标社群。
- 文字、链接等所需内容是否符合预期。
- 是否出现重复消息，或者转发回来源造成循环。

确认结果后，再逐步增加来源频道，并按需要调整监控频率和启停状态。

## 遇到问题

联系支持时，请提供操作系统、来源平台、问题发生时间和现象描述。不要发送账号密码、登录验证码或其他凭据。

如需了解产品适用场景，可返回 [产品介绍](/)。
