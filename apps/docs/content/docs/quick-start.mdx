---
title: 快速开始
description: 按照桌面端的四步向导，创建并运行你的第一个 Discord 采集任务。
---

建议先选择一个来源频道，确认采集和接收结果后，再增加频道数量。

## 1. 准备桌面应用

安装并打开 CopyFast 与 Discord 桌面应用，登录 Discord，切换到需要采集的服务器，确保频道侧栏可见。

在 CopyFast 的「连接与权限」页面检测本机环境，按界面提示完成授权。macOS 需要为 CopyFast 开启辅助功能权限；当前 Discord 识别方式无需截屏或上传屏幕。

准备好目标 Discord 频道的 Webhook 地址，用于接收采集消息。

## 2. 新建任务

打开「新建采集任务」，依次完成四个步骤。

### 选择平台

选择 Discord，确认桌面应用已安装并可打开。

### 定位来源

按照引导开始识别。CopyFast 会暂时隐藏主窗口，读取 Discord 当前服务器与频道侧栏。识别期间尽量避免切换窗口或操作鼠标键盘。

点击悬浮的「退出识别」或按 Esc，可暂停识别并查看已发现频道。你可以继续识别，也可以选择已发现的频道返回配置；部分结果不代表已识别全部频道。

### 频道对应

勾选需要采集的来源频道，在每一行填写对应的 Discord Webhook 地址。

- 每个已选来源频道都必须填写有效地址。
- 多个来源频道可以使用同一个 Webhook，各行配置独立保存。
- 未勾选的频道不会加入任务采集范围。
- 地址默认隐藏；配置页面只校验格式，不会发送测试消息。

### 采集规则

已有任务可在「采集规则 → 编辑规则 → 采集起点」中选择「从现在开始」「最近 1 小时」或「最近 24 小时」。默认保留原采集起点；重新选择的相对时间范围按保存时刻计算，已记录的消息不会重复采集。

| 设置           | 说明                                                                                              |
| -------------- | ------------------------------------------------------------------------------------------------- |
| 任务名称       | 使用方便辨认的名称，例如「产品社区更新」。                                                        |
| 检查频率       | 可选 30 秒、1 分钟、5 分钟，或自定义 10–86400 秒；默认 1 分钟。                                   |
| 首次采集范围   | 可选开始运行后新增的消息、最近 1 小时或最近 24 小时。时间范围只筛选可读取的消息，不保证补齐历史。 |
| 采集内容       | 选择文字消息、图片与附件信息，至少保留一项。                                                      |
| 滚动并标记已读 | 新任务默认开启；采集并发送成功后尝试滚动到最新消息。Discord 也可能在打开频道时自行标记已读。      |

确认预览后，点击「保存任务配置」。**新任务默认暂停，需要手动启动。**

## 3. 启动并检查结果

启动任务后，CopyFast 按设定频率检查所选频道：打开有未读提示的频道，读取当前可访问的消息，按规则筛选并保存，再发送到对应 Webhook；已读频道会跳过。

在来源频道出现符合规则的新消息后，检查以下位置：

- **消息列表**：查看本机已保存的消息。
- **任务日志**：查看本轮采集与发送结果，定位跳过或异常原因。
- **目标 Discord 频道**：确认消息实际到达，内容和接收位置符合预期。

选择频道可同时筛选消息与日志；「全部频道」汇总当前任务范围。已保存记录不代表消息一定发送成功，请结合日志和目标频道核对。

## 4. 调整与暂停

在任务详情中，通过「编辑规则」调整采集设置，通过「编辑对应」修改接收频道名称和 Webhook。

- **仅保存，不运行**：保存配置并暂停任务。
- **保存并运行**：先保存配置，再启动任务；启动失败时，界面会提示配置已保存但任务未启动。

需要停止采集时，暂停任务即可，已保存记录仍可查看。更多排查方法见 [常见问题](/faq)。
