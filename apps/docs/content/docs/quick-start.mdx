本页帮助你完成第一次使用：选择关注的信号来源，打开交易对，查看信号在 K 线上的位置，并用基础指标判断是否值得继续跟踪。

## 1. 先选择你要观察的信号来源

SignalFast 适合同时观察多个交易员或 KOL，而不是只看单个群里的即时消息。

第一次使用可以从这几类来源开始：

| 来源类型     | 适合观察什么                         |
| ------------ | ------------------------------------ |
| 交易员 / KOL | 过去信号是否稳定，是否经常追涨杀跌   |
| Telegram 群  | 群消息是否完整，是否只展示盈利截图   |
| Discord 社区 | 信号是否分散在多个频道，是否方便复盘 |
| 自选关注列表 | 只保留你真正想长期跟踪的来源         |

建议先少量选择 3 到 5 个来源，避免一开始就被太多信号淹没。

## 2. 打开交易对和时间周期

进入信号面板后，选择你关心的交易对，例如 BTC、ETH 或其他高流动性标的。

然后选择时间周期：

| 时间周期 | 更适合                         |
| -------- | ------------------------------ |
| 5m / 15m | 查看短线信号是否追高、是否延迟 |
| 1h / 4h  | 判断信号是否贴近趋势结构       |
| 1d       | 观察中长线观点和大级别位置     |

第一次使用建议从 1h 或 4h 开始，因为它比分钟线更容易看清信号和行情结构的关系。

## 3. 看信号是否落在合理位置

不要只看“买入”或“卖出”两个字。更重要的是信号出现的位置。

重点看：

- 信号是否出现在连续上涨后的高位。
- 信号是否出现在关键支撑或压力附近。
- 多个来源是否在同一区域出现相同方向。
- 信号发出后，行情是否快速反向。
- 这个来源过去是否经常在极端波动后才发信号。

## 4. 用历史表现过滤信号源

一个信号源偶尔命中并不代表稳定。建议优先看长期指标。

| 指标     | 你应该关注的问题                       |
| -------- | -------------------------------------- |
| 胜率     | 是否只靠少数大行情撑起表现             |
| 最大回撤 | 连续失误时你是否能承受                 |
| 信号频率 | 是稳定输出，还是只在热点行情刷屏       |
| 盈亏比   | 单次盈利和亏损是否对称                 |
| 完整记录 | 是否包含失败信号，而不是只展示盈利案例 |

SignalFast 不保证交易结果，它的价值是帮你更快排除不透明、不稳定、无法复盘的信号源。

## 5. 结合博客理解不同渠道

如果你正在对比喊单群，可以先读这两篇：

- [SignalFast 对比 Telegram 喊单群：交易信号到底该怎么追踪](http://signalfast.localhost:4101/blog/signalfast-vs-telegram-signal-groups)
- [SignalFast 对比 Discord 喊单群：频道热闹不等于信号可靠](http://signalfast.localhost:4101/blog/signalfast-vs-discord-signal-groups)

它们会从用户体验、真实性和成本几个维度解释为什么聊天群适合接收消息，但不一定适合长期评估信号质量。

## 第一次使用建议

- 先从只读分析开始，不要急着跟单。
- 不要因为某个来源短期连续命中就加大仓位。
- 对承诺高收益、只展示盈利截图、要求额外充值的来源保持谨慎。
- 用 K 线位置和历史表现判断信号，而不是只看群内气氛。
