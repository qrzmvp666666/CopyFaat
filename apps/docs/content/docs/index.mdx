CopyFast 帮助你在本机关注 Discord 频道，将采集到的消息发送到指定的 Discord Webhook，减少反复查看和手动复制消息的工作。

## 你可以做什么

- **识别来源频道**：从已登录的 Discord 桌面应用中识别当前服务器与频道，勾选需要关注的频道。
- **配置消息接收**：为每个来源频道填写目标频道的 Webhook，多个来源也可以发送到同一个地址。
- **设置采集规则**：调整检查频率、首次采集范围，以及文字、图片与附件信息选项。
- **管理任务与记录**：启动或暂停任务，按频道查看已保存消息和任务日志，随时修改规则与接收对应。

## 从这里开始

1. 阅读 [快速开始](/quick-start)，完成第一个 Discord 采集任务。
2. 遇到识别、采集或发送问题时，查看 [常见问题](/faq)。

## 当前支持范围

当前桌面端提供 Discord 任务配置，Telegram 自动识别尚未接入。

采集依赖 Discord 桌面应用当前可读取的消息内容，不保证获取完整历史记录。图片与附件目前转发可读取的名称或描述信息，不下载和上传原始文件。

任务配置、采集记录保存在本机；运行任务后，消息会发送到你配置的 Webhook。请保持 CopyFast 和 Discord 桌面应用运行，并确保网络可用。
